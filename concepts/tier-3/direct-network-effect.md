# Direct (Same-Side) Network Effect

> **Value grows as users of the same type join the platform.**

## Definition

**Short:** A subtype of Network Effect in which value grows as users of the same type join (telephone networks, social media).

## Canonical example

A social network — more users of the same type (people wanting to socialise) makes the network more valuable to each user.
