# Indirect (Cross-Side) Network Effect

> **Value grows as users of different types join the platform.**

## Definition

**Short:** A subtype of Network Effect in which value grows as users of different types join (more developers → more users → more developers).

## Canonical example

The App Store — more developers attract more users, and more users attract more developers.
